# LLM 量化策略生成能力评测（第二阶段）

评测 13 个主流大语言模型在真实 A 股规则下**自主编写量化交易策略**的能力。

## 核心数据

- 股票数：5300 只（对齐沪深北三市）
- 交易日：252 天
- 行业数：10 个（按真实市值加权）
- 迭代轮次：4 轮（每轮 AI 根据反馈优化代码）
- 训练/测试种子：6 / 18（严格分离）
- 新闻库：1962 条（4 家 AI 共创）

## 最终排名

| 排名 | 模型 | 总分 | 平均收益 |
|---|---|---|---|
| 🥇 | Claude-Opus-5 | 87.0 | -10.68% |
| 🥈 | Seed-2.1-Turbo | 82.5 | -7.29% |
| 🥉 | DeepSeek-V4-Pro | 73.0 | -12.22% |

完整结果见 `docs/第二阶段评测报告.md`。

## 目录结构

- `src/` — 核心代码（市场模拟器、代码沙箱、模型配置）
- `scripts/` — 评测脚本（主循环、评分、绘图）
- `data/strategies/` — 各模型 4 轮策略代码
- `data/contest_results/` — 回测结果
- `docs/` — 报告
- `figures/` — 图表

## 与第一阶段的区别

- 第一阶段：AI 扮演**交易员**，每日输出仓位
- 第二阶段：AI 扮演**量化研究员**，写策略代码
