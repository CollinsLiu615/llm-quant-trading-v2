# LLM 量化交易能力评测：六模型在真实 A 股规则下的表现

## 摘要

本研究构建了一个包含 GARCH 波动率聚集、行业板块联动、三态市场切换、黑天鹅事件与完整 A 股交易规则（T+1、印花税、涨跌停、最小交易单位）的市场模拟器，对六个主流大语言模型进行了为期 180 个交易日、两轮独立市场的量化交易能力评测。

**核心发现**：

1. 所有六个模型均跑赢基线策略（随机 -14.81%、动量 -4.52%），平均收益在 +4.07% 至 +22.33% 之间；
2. **DeepSeek-V4.1-Flash（官方 API）以 +22.33% 平均收益夺冠**，但收益波动极大（标准差 16.68），第 2 轮单轮收益高达 +39.01%；
3. **同一家族不同版本间差异显著**——DeepSeek 官方 V4.1（+22.33%）是 DeepSeek-V4-Flash-0731（+8.05%）的 2.8 倍；
4. **六个模型展现出六种截然不同的决策风格**，从极度保守到激进追涨；
5. **"分析能力"不等于"执行能力"**——Claude-Sonnet-5 的技术分析理由最专业，但因频繁交易导致收益被交易成本侵蚀。

---

## 1. 研究背景

大语言模型（LLM）在自然语言任务上表现优异，但其在**需要多步推理、风险权衡、动态决策**的金融交易场景中的能力尚不明确。

本研究试图回答三个问题：
- LLM 能否在真实 A 股规则下产生超额收益（alpha）？
- 不同 LLM 的决策风格是否有显著差异？
- 模型版本升级对交易能力的影响有多大？

## 2. 实验设计

### 2.1 市场模拟器 V3

与常见的几何布朗运动模拟器不同，本研究的市场模拟器引入了五层复杂度：

| 机制 | 说明 |
|---|---|
| **GARCH(1,1) 波动率聚集** | α=0.10, β=0.85，波动持久性 0.95，模拟"大波动后接大波动" |
| **行业板块联动** | 15 只股票分配至 2 个行业，同行业相关性 0.7，跨行业 0.3 |
| **三态市场切换** | 牛市（μ=10%，σ=20%）/ 震荡（μ=0%，σ=25%）/ 熊市（μ=-20%，σ=40%） |
| **黑天鹅跳跃** | 每日 0.1% 概率触发 ±15% 的跳空 |
| **新闻事件系统** | 4 类事件（政策/突发/情绪/财报），含衰减与行业扩散 |

### 2.2 交易规则（完整 A 股）

| 规则 | 参数 |
|---|---|
| 佣金 | 万分之三，最低 5 元 |
| 印花税 | 千分之一（仅卖出） |
| 过户费 | 十万分之一 |
| 滑点 | 万分之五 |
| T+1 | 当日买入次日才能卖出 |
| 涨跌停 | ±10%，触及无法成交 |
| 最小交易单位 | 100 股一手 |
| 做空 | 禁止 |

### 2.3 评测配置

| 参数 | 值 |
|---|---|
| 交易日 | 180 天 |
| 轮数 | 2 轮（不同 seed） |
| 股票数 | 15 只 |
| 初始资金 | 100,000 元 |
| 观察窗口 | 20 日价格 + 5 日新闻 |

### 2.4 参赛模型

| 别名 | 实际模型 | 来源平台 | 轮数 |
|---|---|---|---|
| DeepSeek-V4.1-Flash | DeepSeek-V4.1-Flash | DeepSeek 官方 API | 2 |
| DeepSeek-V4-Flash-0731 | DeepSeek-V4-Flash-0731 | 华东师大部署 | 2 |
| Qwen3.8-27B | Qwen3.8-27B | 华东师大部署 | 2 |
| GLM-5.3-Flash | GLM-5.3-Flash | 智谱 BigModel | 2 |
| GLM-5.3-FlashX | GLM-5.3-FlashX | 智谱 BigModel | 2 |
| Claude-Sonnet-5 | Claude-Sonnet-5 | CodeCraft 中转 | 1 |

> **注**：华东师大 ChatECNU 平台提供两个对话模型，其底层分别是 DeepSeek-V4-Flash-0731 和 Qwen3.8-27B，本报告统一使用底层真实模型名。

## 3. 评测结果

**关键观察**：
- 六个 AI 模型**全部跑赢随机策略和动量策略**，产生显著 alpha
- 收益第一与第六相差 **5.5 倍**
- 收益标准差与平均收益正相关——**高收益往往伴随高波动**

### 3.2 分家族分析

**DeepSeek 家族**：
- 官方 V4.1：平均 +22.33%
- DeepSeek-V4-Flash-0731：平均 +8.05%
- **同一家族，版本差导致 2.8 倍收益差距**

**GLM 家族**：
- FlashX：平均 +11.80%（但波动大）
- Flash：平均 +4.07%（稳健）

**其他**：
- Claude-Sonnet-5：仅 1 轮 +7.35%，跑赢大部分两轮模型
- Qwen3.8-27B：稳健但保守，两轮均小赚

## 4. 决策风格深度分析

### 4.1 六种风格画像

**Claude-Sonnet-5 —— "技术分析师"**
- 首次建仓：Day 3~4
- 典型理由："股票4价上5日均线且连续稳步上涨"
- 风格：技术分析词汇最多，关注均线、量价、动量
- 弱点：频繁进出，交易成本高

**DeepSeek-V4.1-Flash —— "情绪敏感型"**
- 首次建仓：Day 1
- 典型理由："IPO 扩容传言压制情绪"、"北向资金流入情绪转暖"
- 风格：对新闻事件极度敏感
- 特点：**抓大行情能力强**——第 2 轮三次集中押注均大赚

**GLM-5.3-FlashX —— "激进顺势者"**
- 首次建仓：**Day 0 就满仓 60%**
- 风格：**最激进**，敢于在信息不足时下重注
- 结果：两轮 -0.97% / +24.57%，**高风险高收益**

**DeepSeek-V4-Flash-0731 —— "稳健灵活"**
- 首次建仓：Day 1
- 风格：**均衡派**，仓位灵活调整
- 结果：两轮 +6.45% / +9.65%，**波动最小（±1.60）**

**Qwen3.8-27B —— "极度保守"**
- 首次建仓：**Day 0~3 连续 4 天空仓**
- 风格：**最保守**——只在信号明确时才入场
- 结果：两轮 +4.91% / +7.72%

**GLM-5.3-Flash —— "先观察后发力"**
- 首次建仓：Day 0（99% 满仓）
- 风格：初期激进，中后期转为审慎
- 结果：两轮 +0.47% / +7.67%

### 4.2 三个关键决策时刻

#### 时刻 1：Day 0 —— 信息为零的开局

| 模型 | 仓位 | 原话理由 |
|---|---|---|
| GLM-5.3-Flash | 99% | "投资周期较长，采用等权分散配置" |
| GLM-5.3-FlashX | 60% | "温和建仓，保留40%现金" |
| Claude-Sonnet-5 | 34% | "IPO传言致观望偏空，防御" |
| DeepSeek-V4.1-Flash | 0% | "无新闻与有效信号，保持现金" |
| DeepSeek-V4-Flash-0731 | 0% | "无可用的新闻、历史趋势" |
| Qwen3.8-27B | 0% | "缺乏波动特征及新闻驱动" |

#### 时刻 2：Day 7 —— IPO 扩容利空

| 模型 | 仓位变化 | 应对策略 |
|---|---|---|
| DeepSeek-V4.1-Flash | 70% → 30% | 大幅减仓 |
| DeepSeek-V4-Flash-0731 | 70% → 80% | **逆势加仓** |
| Qwen3.8-27B | 0% → 0% | 继续空仓 |
| GLM-5.3-Flash | 30% → 30% | 按兵不动 |
| GLM-5.3-FlashX | 25% → 25% | 保持防守 |
| Claude-Sonnet-5 | 80% → 33% | 分级减仓 |

#### 时刻 3：Day 10 —— 北向资金 + 医药监管

| 模型 | 从 Day 9 到 Day 10 的仓位 |
|---|---|
| DeepSeek-V4.1-Flash | 0% → 50% |
| DeepSeek-V4-Flash-0731 | 30% → 20%（减仓） |
| Qwen3.8-27B | 64% → 95%（大幅加仓） |
| GLM-5.3-Flash | 22% → 42% |

## 5. 关键洞察

### 5.1 版本差异 > 家族差异

DeepSeek 官方 V4.1 vs DeepSeek-V4-Flash-0731，同一家族，收益差 2.8 倍。

**结论**：模型版本对交易能力的影响，可能大于模型家族之间的差异。

### 5.2 分析能力 ≠ 执行能力

Claude-Sonnet-5 决策理由最专业，但收益仅 +7.35%。

**量化证据**：Claude 180 天累计调仓约 60 次，累计交易成本约 3.9%，**超过总收益的一半**。

### 5.3 高收益伴随高波动

| 模型 | 收益 | 波动（std） |
|---|---|---|
| DeepSeek-V4.1-Flash | +22.33% | ±16.68 |
| GLM-5.3-FlashX | +11.80% | ±12.77 |
| DeepSeek-V4-Flash-0731 | +8.05% | **±1.60** |

### 5.4 交易成本是隐形杀手

| 模型 | 调仓次数 | 累计成本 | 收益 | 成本占比 |
|---|---|---|---|---|
| Claude-Sonnet-5 | ~60 | ~3.9% | +7.35% | 53% |
| DeepSeek-V4.1-Flash | ~40 | ~2.6% | +22.33% | 12% |
| DeepSeek-V4-Flash-0731 | ~35 | ~2.3% | +8.05% | 29% |
| Qwen3.8-27B | ~20 | ~1.3% | +6.32% | 21% |

## 6. 工程实践与踩坑记录

### 6.1 平台限制的真实体验

- **智谱 GLM-4.7-Flash**：免费档并发上限 1，单次调用需等 20~30 秒，最终放弃
- **硅基流动 Xing4.0-29B**：累计 40K tokens 后服务端静默拒绝，TCP 连接成功但无响应
- **DeepSeek 官方 API**：`max_tokens=4096` 被推理吃光，50.7% 响应无法解析，需改 `reasoning_effort="low"`

### 6.2 数据清洗

Claude 日志污染事件：早期小规模测试的 29 条数据残留，通过对比各模型同一天新闻事件发现，修复方式为截取 t=0 开始的 179 条。

## 7. 结论与启示

### 7.1 核心结论

1. **LLM 具备真实 alpha 能力**：六个模型全部跑赢随机与动量基线
2. **AI 投资风格高度分化**：从极度保守到激进追涨，差异远超预期
3. **版本升级带来实质提升**：DeepSeek V4.1 显著优于 V4-Flash-0731
4. **"分析"与"执行"是两种能力**：Claude 的分析质量最高但收益不是
5. **交易成本决定长期胜败**：高频调仓会侵蚀大部分收益

### 7.2 对 LLM 量化应用的启示

- **不要迷信单轮结果**：两轮差异可达 30%+
- **交易频率控制是必要的**：给 LLM 加入"最小调仓间隔"约束
- **版本比家族更重要**：选型时关注最新版本
- **组合不同风格的 LLM**：稳健型 + 激进型可能优于单一模型

### 7.3 研究局限

- **样本量有限**：2 轮 × 180 天
- **市场模拟器仍是合成数据**
- **未考虑滑点动态**
- **Claude 仅 1 轮**：因平台额度限制
